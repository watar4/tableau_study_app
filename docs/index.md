## 本ツールの使い方

1. 「学習を始める」から順に進めてください。
2. 各章は「学習目標 → 解説 → やってみよう → クイズ」で構成されています。
3. クイズはすべて ○× 形式です。回答するとその場で正誤と解説が表示されます。
4. 学習進捗は下記の進捗バッジで確認できます。

<ProgressBadge />

## 想定学習時間

合計 **約 20 時間**。1 日 1〜2 章のペースで進めると、2〜3 週間で完走できます。

## 対象範囲

- Tableau **Desktop** を主たる対象とします（Cloud / Server は概要のみ触れます）。
- 演習データは **City of Chicago Open Data Portal** の Taxi Trips を抽出した `.hyper` を使用します。
- 文体は「ですます」調、画像・GIF を活用した解説で進めます。
