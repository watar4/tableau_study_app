## 1. ダッシュボードの作成手順

**ダッシュボード**は、複数のワークシートを 1 つの画面に組み合わせて、関連する情報を一度に見せるための画面です。Tableau の利用は最終的に「ダッシュボードを作って共有する」ところに着地することが多く、シート単位の品質と同じくらいダッシュボードの構成力が重要になります。

作成手順の概要は次のとおりです。

1. 必要なワークシートをすべて完成させておく
2. ワークブック下部のタブ列にある「**新しいダッシュボード**」アイコンをクリック
3. 左サイドバーの「**シート**」一覧からドラッグ&ドロップで配置
4. オブジェクト（テキスト・画像・Web など）を補強として追加
5. フィルター・凡例の適用範囲、タイトル、ツールヒントなどを調整
6. アクションを設定して対話性を持たせる（次章）

## 2. サイズ設定（固定 / 自動 / レンジ）

ダッシュボードは画面サイズを意識して作るのが基本です。左サイドバー下部の「**サイズ**」セクションで、3 つのモードから選びます。

| モード | 動作 | 向くケース |
|--------|------|------------|
| **固定サイズ (Fixed)** | 指定したピクセルで固定。表示環境を選ばず同じ見た目になる | Tableau Public 公開・印刷用 PDF・社内共有用 |
| **自動 (Automatic)** | ブラウザの画面サイズに合わせて伸縮 | 単一の閲覧環境にぴったり合わせたい場合 |
| **レンジ (Range)** | 最小/最大サイズを指定し、その間で伸縮 | 多様な画面サイズに「ある程度」適応させたい場合 |

### よく使うプリセット

- デスクトップブラウザ: 幅 1000 〜 1366 px、高さ 700 〜 800 px
- 大型モニタ: 1920 × 1080 など
- タブレット: 768 × 1024 程度

::: info 固定サイズが基本
公開・配布用のダッシュボードは「**固定サイズ**」が無難です。自動 / レンジは便利な反面、配置がズレて意図しない見た目になることがあり、配信前の確認コストが高くなります。
:::

## 3. シートを配置する（タイル / 浮動）

ダッシュボード上のシートやオブジェクトの配置方法には 2 種類あります。

| 方式 | 説明 | 特徴 |
|------|------|------|
| **タイル (Tiled)** | 隣接するオブジェクトと自動的に整列・伸縮する | レイアウトが崩れにくい。組みやすい |
| **浮動 (Floating)** | 絶対位置で配置。他のオブジェクトに干渉しない | 自由度が高い。微妙なズレが起きやすい |

**基本はタイルで組む**のが推奨です。タイル方式だと、シートのサイズを変えると他のシートも自動で押し出されて整列を保ってくれます。

浮動を使うべきケース:

- KPI カードをグラフの上に重ねたい
- 凡例やフィルターをグラフの内側に配置したい
- 装飾用の半透明オーバーレイを置きたい

::: warning 浮動を多用しない
浮動だらけのダッシュボードは「サイズ変更時にズレる」「メンテナンスでオブジェクトを動かすと他もズレる」といったトラブルが起きやすくなります。まずはタイル+コンテナで構造を作り、どうしても必要な箇所だけ浮動にしましょう。
:::

---

## 4. レイアウトコンテナ（水平 / 垂直）

**レイアウトコンテナ**は、複数のシート/オブジェクトをグループ化して整列させる入れ物です。コンテナを上手に使うと、サイズ変更時にもレイアウトが崩れにくくなり、保守性が大幅に上がります。

| コンテナ | 動作 |
|----------|------|
| **水平 (Horizontal)** | 中身を左から右へ並べる |
| **垂直 (Vertical)** | 中身を上から下へ並べる |

ネスト（入れ子）して組み合わせることで、複雑なレイアウトも組めます。

### よくある構成パターン

- 全体を「垂直コンテナ」で包み、上から順に「タイトル / KPI行 / メイングラフ / 詳細表」
- KPI 行は「水平コンテナ」で 4 枚のテキストオブジェクトを並べる
- メイングラフ部は「水平コンテナ」で「左にトレンド、右に構成比」

## 5. オブジェクト

ワークシート以外にもダッシュボードに追加できる**オブジェクト**があります。左サイドバー下部からドラッグして配置します。

| オブジェクト | 用途 |
|--------------|------|
| **テキスト** | タイトル・説明文・注釈。パラメーター値も埋め込み可能 |
| **画像** | ロゴや背景画像。URL リンクを設定することもできる |
| **Web ページ** | 任意の URL を埋め込む。URL アクションと組み合わせて動的に変更可能 |
| **空白** | 余白を空けて整列を整える調整用 |
| **水平/垂直コンテナ** | レイアウトの骨格 |
| **ナビゲーション** | 別のダッシュボードやシートに遷移するボタン |
| **ダウンロード** | PDF / 画像 / クロス集計 / ワークブックのダウンロードボタン |
| **エクステンション** | サードパーティ製のミニアプリを埋め込む |

### エクステンション

エクステンションは Tableau Exchange からダウンロードして利用する Web 拡張です。書き込みフォームや高度なチャートなど、標準機能では実現しにくい挙動を追加できますが、外部サーバとの通信が発生する場合があるため、社内利用の場合はセキュリティポリシーを確認してください。

## 6. フィルターと凡例の適用範囲

シート単体ではフィルターはそのシートだけに効きますが、ダッシュボードでは「**他のシートにも効かせるか**」を細かく制御できます。シートを選択 → タイトルバー右の▼ → 「**フィルター**」 → フィールド名 で、フィルターをダッシュボードに表示できます。

表示されたフィルターを右クリック → 「**ワークシートに適用**」で適用範囲を選びます。

| 適用範囲 | 動作 |
|----------|------|
| **このワークシートのみ** | 出元のシートだけに適用 |
| **このデータソースを使用するすべて** | 同じデータソースのすべてのシートに適用 |
| **関連するすべてのデータソースに適用** | 共通フィールド経由で別データソースのシートにも連動 |
| **選択したワークシート** | 適用するシートを個別に選べる |

### 関連するシートのみに効かせる

複数のデータソースを使うダッシュボードでは「**関連するシートのみ**」を選ぶと、フィルター対象フィールドが存在するシートにだけ効くため、安全です。

### 凡例の共有

複数のシートで同じディメンション（例: `payment_type`）を色に使っている場合は、凡例を 1 つだけダッシュボードに表示し、他は非表示にすると見た目が整理されます。

::: info カラーの整合性
「会社A は青、会社B は赤」のように色を意味づけで使う場合は、シート間で一致するように「**カラーの編集**」で割り当て色を保存しておきましょう。
:::

## 7. デバイスデザイナーの概要

**デバイスデザイナー**は、デスクトップ・タブレット・電話など複数の画面サイズ向けに、別レイアウトを定義できる機能です。

- ダッシュボード上部の「**デバイスプレビュー**」をクリックして開く
- 「デバイスレイアウトの追加」でターゲットデバイスを追加
- 各デバイス用に、シートの並べ替え・サイズ変更・除外などを行う

公開後、閲覧者の画面サイズに応じて Tableau が最適なレイアウトを自動選択します。なお、デバイスレイアウトは元のダッシュボードのシートを **共通に使い回す** ため、デバイスごとに別のシートを作り直す必要はありません。表示するシートの取捨選択や配置だけをデバイスごとに変えられます。

## 8. アクセシビリティへの配慮

ダッシュボードは多様な利用者が見ます。設計段階から以下を意識すると、誰にとっても読みやすいダッシュボードになります。

### 色覚多様性への配慮

- 色だけで意味を区別しない（形・パターン・ラベルも併用）
- 「赤と緑だけで損益を表す」のはハイリスク。橙とシアン、青と橙などのコンビが安全
- Tableau のデフォルトパレット「**Color Blind**」は色覚多様性を考慮した配色

### コントラストとフォント

- 背景色と文字色のコントラストを十分に確保（薄いグレー文字は避ける）
- フォントサイズは KPI で大きく、軸ラベル・凡例で小さく、というメリハリ
- 同じビュー内でフォントを混在させすぎない

### テキスト代替

- 各シートに分かりやすい**タイトル**を付ける
- ツールヒントに**説明的な文章**を入れる（数字だけでなく文脈も）
- 重要な傾向は注釈で言葉として書く

::: tip 「3 秒テスト」
ダッシュボードを開いた閲覧者が **3 秒以内に「何の画面か」を理解できるか** をチェックしてみましょう。タイトル・KPI・色の意味が瞬時に分からない場合は、配置や強調を見直すサインです。
:::

## やってみよう

Chicago Taxi データを使い、シンプルなダッシュボードを 1 つ組み立てます。

1. **シートを 3 つ用意**
   - シートA: `payment_type` 別の `SUM(trip_total)` 棒グラフ
   - シートB: 月次の `SUM(trip_total)` 折れ線（`trip_start_timestamp` の連続月）
   - シートC: `company` 別の `SUM(trip_total)` 上位 10 件
2. **新しいダッシュボードを作成**
   - サイズ「固定サイズ」 → 「デスクトップブラウザ (1000 x 800)」を選択
3. **垂直コンテナで骨格を作る**
   - 「垂直」コンテナをドラッグして全面に配置
4. **タイトルテキストを追加**
   - 「テキスト」オブジェクトを上部に置き、「シカゴタクシー 売上ダッシュボード 2023」と入力。フォントを大きめに設定
5. **シートを配置**
   - 上段に「水平」コンテナを置き、シートA とシートB を左右に並べる
   - 下段にシートC を全幅で配置
6. **フィルターを共有**
   - シートB のタイトルバー▼から「フィルター」 → `payment_type` を表示
   - 右クリック → 「ワークシートに適用」 → 「このデータソースを使用するすべて」
7. **凡例を整理**
   - 色凡例が重複していたら 1 つに統一し、他は非表示
8. **モバイル用レイアウトを追加（任意）**
   - 「デバイスプレビュー」 → 「電話」レイアウトを追加し、上下に積み直す

## まとめ

- ダッシュボードは「シートを並べる場所」というより「閲覧者に物語を伝える画面」です。
- サイズ設定は **固定** が公開・配布用の基本で、自動 / レンジは画面適応が必要な場合のみ使います。
- **タイル + レイアウトコンテナ**で骨格を組み、必要な箇所だけ**浮動**を使うとメンテナンスしやすくなります。
- フィルター・凡例の適用範囲は「関連するシートのみ」「データソース全体」などから慎重に選びます。
- **デバイスデザイナー**で複数解像度に対応できますが、メンテナンスコストとのバランスを見極めましょう。
- 色・コントラスト・テキスト代替の観点で、多様な利用者に届くダッシュボードを意識しましょう。
