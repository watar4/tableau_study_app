# 用語集

Tableau Desktop と関連分野の主要用語をまとめます。各用語の詳細解説は、関連する章を参照してください。

## A

### Aggregation(集計)
複数の行を SUM / AVG / COUNT などの関数でひとつの値にまとめる操作。Tableau ではメジャーをビューに置いた瞬間に自動で集計が適用されます。

### Action(アクション)
ユーザーの操作(クリック・ホバー・メニュー選択)に応じてダッシュボードを動的に変化させる仕組み。フィルター / ハイライト / URL / パラメーター / セット値の変更 / シートに移動 の 6 種類があります。詳細は [15. アクション](/15-actions/)。

### ATTR
集計関数のひとつ。ビュー粒度に対して値が一意ならその値を、複数あれば `*` を返します。ツールヒントに「集計粒度に依存しない属性」を表示したい場面で使用します。

## B

### Bin(ビン)
連続値(数値・日付)を一定の幅で区切って離散カテゴリに変換したもの。ヒストグラム作成の基本道具です。固定幅 / パラメーター連動の変動幅が選べます。

## C

### Calculated Field(計算フィールド)
データソースの列とは別に、ワークブック内で式によって作成する論理的な列。元データを変更せず、Tableau 側だけで保持されます。詳細は [06. 計算フィールド基礎](/06-calc-basics/)。

### CASE 文
等価比較に特化した条件分岐構文。`CASE [field] WHEN '値1' THEN '結果1' WHEN '値2' THEN '結果2' ELSE 'その他' END` の形で書きます。大小比較や複合条件には IF を使う必要があります。

### Context Filter(コンテキストフィルター)
ディメンションフィルターの中で「先に評価する」と宣言したもの。フィルターピル右クリック →「コンテキストに追加」で設定し、ピルが灰色になります。上位 N の対象を絞ったり、FIXED LOD に効かせるために使います。

### Continuous(連続)
フィールドが「範囲を持つ値」として扱われる状態。ビューに置くと **軸** が作られ、ピルは **緑色** になります。

### COUNTD
重複を除いたユニーク値の数を返す集計関数。`COUNTD([taxi_id])` で稼働した実車両数を求める、といった用途。基数の高い列に対しては重い処理になりがちです。

## D

### Dashboard(ダッシュボード)
複数のワークシートやテキスト・画像・Web ページを 1 つの画面にまとめたビュー。閲覧者が一度に複数の情報を見られるように構成します。詳細は [14. ダッシュボード基礎](/14-dashboard/)。

### Data Interpreter(データインタープリター)
Excel / Google Sheets / PDF / HTML テーブルから、ヘッダー誤りや結合セルを自動補正してテーブル形式に整える機能。CSV には適用されません。

### DATEPARSE
文字列を任意のフォーマットで日時に変換する関数。フォーマット指定が必須です。`DATEPARSE("yyyy-MM-dd", "2023-04-15")` のように使います。一部のライブ接続データソースではサポートされません。

### DATEDIFF
2 つの日時の差を指定単位で返す関数。`DATEDIFF('day', a, b)` は b − a の日数を返します。第 4 引数で週開始曜日を指定可能。

### DATETRUNC
日時を指定単位の境界に切り捨てる関数。`DATETRUNC('month', dt)` は月初 00:00 に揃えます。月次集計を作るときの定番。

### Dimension(ディメンション)
質的データを表すフィールドで、集計の「**軸**」になります。データペインの上半分に配置され、自動判定は文字列・日付などに対して行われます。詳細は [01. 基本概念](/01-basics/)。

### Discrete(不連続)
フィールドが「個別の値」として扱われる状態。ビューに置くと **ヘッダー** が作られ、ピルは **青色** になります。

## E

### Extract(抽出)
データソースをローカル `.hyper` ファイルに取り込んだもの。ライブ接続より高速で、配布も容易。本ツールでは Chicago Taxi 2023 の `.hyper` を演習データとして同梱しています。詳細は [03. 抽出 vs ライブ接続](/03-extract-vs-live/)。

## F

### FIXED LOD
指定したディメンションの粒度に固定して集計する LOD 表現。`{ FIXED [company] : SUM([trip_total]) }` のように書きます。ビュー粒度に依存しない集計を作れます。

## H

### Hyper
Tableau の高速インメモリエンジン。`.hyper` ファイルはこのエンジン用のデータ抽出フォーマットです。

## I

### IF / THEN / ELSEIF / ELSE / END
任意の条件式を扱える分岐構文。大小比較・複合条件にも使えます。END は省略不可です。

### IIF
3 引数(条件、真値、偽値) または 4 引数(+ NULL 時の値) の条件分岐関数。短い分岐を 1 行で書くのに便利。

### IFNULL
第 1 引数が NULL のとき第 2 引数を返す関数。任意型に使えます。数値の NULL を 0 にしたい場合は ZN が専用に使えます。

### INCLUDE LOD
ビューに含まれていないディメンションを集計時に「含めて」粒度を細かくする LOD 表現。

### INDEX
表計算関数のひとつ。パーティション内の現在行の位置を **1 始まり** で返します。「上位 N だけ強調」のような表現に活用。

## L

### LOD(Level of Detail)
集計の粒度を計算式で明示する仕組み。FIXED / INCLUDE / EXCLUDE の 3 種類があります。詳細は [12. LOD 表現](/12-lod/)。

### LOOKUP
表計算関数。オフセットを指定して前後の行の値を取得します。`LOOKUP(SUM([trip_total]), -1)` で 1 つ前の値。

## M

### Mark Card(マークカード)
ビューの「見せ方」を制御する 7 つのシェルフ(マークタイプ / 色 / サイズ / ラベル / 詳細 / ツールヒント / 形状)。詳細は [01. 基本概念](/01-basics/)。

### Measure(メジャー)
量的データを表すフィールドで、集計の「**対象**」になります。データペインの下半分に配置され、デフォルトは連続(緑)です。

## N

### Null(ヌル)
値が存在しない状態。集計関数(SUM, AVG, COUNT) は NULL を除外して計算します。条件式では `ISNULL([field])` で判定。

## P

### Pages Shelf(ページシェルフ)
ページごとにビューをフレーム分割し、アニメーション再生できるシェルフ。時系列の変化を再生するのに使われます。

### Parameter(パラメーター)
ユーザーが値を選んで差し替えられる「単一値の定数」。計算式・フィルター・参照線・タイトル などから参照できます。詳細は [13. パラメーター](/13-parameters-sets/)。

### Parameter Action(パラメーターアクション)
ビュー上のマーククリックでパラメーター値を書き換えるアクション。動的なインタラクションを実現します。

### Performance Recorder(パフォーマンスレコーダー)
ビュー描画にかかったクエリ時間・コンパイル時間・レイアウト時間を計測してレポート化する Tableau Desktop 組み込み機能。

### Pivot(ピボット)
ワイド(横持ち)のテーブルをロング(縦持ち)に変換するデータ準備機能。「年度別の列が並ぶ」構造を「年度 + 値」の 2 列に変換できます。

## Q

### Quick Filter(クイックフィルター)
ダッシュボード上で対話的に値を絞り込める UI 部品。リスト/ドロップダウン/スライダーなど複数モードを切り替えられます。

### Quick Table Calculation(クイック表計算)
よく使う表計算(累計・差・前年比・順位・移動平均 等) を、ピル右クリックメニューから 1 アクションで適用できる機能。

## R

### RANK / RANK_DENSE / RANK_UNIQUE / RANK_MODIFIED
表計算関数。順位を返しますが、同順位の扱いが関数ごとに異なります。
- `RANK`: 同順位を共有し次の順位を飛ばす(1, 2, 2, 4)
- `RANK_DENSE`: 同順位でも次の順位を飛ばさない(1, 2, 2, 3)
- `RANK_UNIQUE`: 同順位でも一意な順位を割り当て(1, 2, 3, 4)
- `RANK_MODIFIED`: 同順位は最後の順位を共有(1, 3, 3, 4)

### REGEXP_EXTRACT / REGEXP_MATCH / REGEXP_REPLACE
正規表現を使った文字列操作関数。REGEXP_EXTRACT はキャプチャグループに一致した部分を返します。

### Relationship(リレーションシップ)
複数テーブルを論理的に結びつける Tableau 2020.2 以降のデフォルト機能。物理結合と違い、テーブルの粒度を保ったままになります。

## S

### Set(セット)
ディメンションの値の部分集合を保存したもの。固定セット / 計算セット(条件・上位) / 動的セットアクション の 3 種類。計算式では IN/OUT のブール値として参照できます。

### Shelf(シェルフ)
ビューの構造を決める配置エリア。列 / 行 / フィルター / ページ / マーク 等があります。

### Show Me
選択中のフィールドの種類と数に応じて、推奨されるチャートタイプをハイライト表示する UI パネル。

### SODA API
Socrata のオープンデータ API。本ツールでは Chicago Data Portal からの取得に使用しています。

### Story(ストーリー)
複数のダッシュボードやシートを時系列に並べて、プレゼン形式で見せる仕組み。

## T

### Table Calculation(表計算)
集計後の値に対して二次的に計算を行う仕組み。WINDOW_SUM / RUNNING_SUM / LOOKUP / RANK / INDEX などの関数があります。詳細は [11. 表計算関数](/11-functions-tablecalc/)。

### Tableau Cloud
Tableau 社がホスティングする SaaS 版。社内認証付きで業務利用向けに共有できます。

### Tableau Public
誰でも無料で使える公開クラウドサービス。アップロードしたワークブックとデータは原則すべて公開されます。

### Tableau Server
オンプレ(自社環境)にインストールして運用する Tableau サーバー製品。社内ネットワーク内で完結します。

### Trend Line(トレンドライン)
散布図などに引かれる回帰直線。線形 / 対数 / 指数 / べき乗 / 多項式 の各モデルが選べます。

## U

### Union(ユニオン)
同じ列構造を持つ複数のテーブルを縦方向に積み重ねるデータ結合方法。

### URL Action(URL アクション)
クリックされたマークのフィールド値を URL に埋め込み、外部 URL を開くアクション。`<フィールド名>` のプレースホルダーが使えます。

## V

### VizQL(Visual Query Language)
Tableau の中核技術。ドラッグ&ドロップ操作を裏側のクエリと可視化に自動変換します。

## W

### WINDOW_SUM / WINDOW_AVG / WINDOW_MIN / WINDOW_MAX
表計算関数。指定したウィンドウ(範囲) 内の集計を返します。移動平均などの実装に使われます。

### Worksheet(ワークシート)
1 つのビュー(チャートや表) を作成・編集する基本単位。複数のワークシートを組み合わせてダッシュボードを構築します。

## Z

### ZN
数値の NULL を 0 に変換する専用関数。`ZN([field])` の形で使用します。文字列の NULL 処理には IFNULL を使います。

## ファイル拡張子

| 拡張子 | 内容 |
|--------|------|
| `.twb` | ワークブック定義のみ(XML)。データを含まない |
| `.twbx` | ワークブック + 抽出 + アセットをまとめたパッケージ |
| `.hyper` | データ抽出ファイル単体 |
| `.tds` | データソース定義のみ |
| `.tdsx` | データソース定義 + 抽出のパッケージ |
