# ショートカット集

Tableau Desktop の主要なキーボードショートカットをまとめます。

## ファイル操作

| 操作 | Windows | Mac |
|------|---------|-----|
| 新規ワークブック | Ctrl + N | Cmd + N |
| ワークブックを開く | Ctrl + O | Cmd + O |
| ワークブックを保存 | Ctrl + S | Cmd + S |

## 編集操作

| 操作 | Windows | Mac |
|------|---------|-----|
| 元に戻す | Ctrl + Z | Cmd + Z |
| やり直し | Ctrl + Y | Cmd + Shift + Z |
| コピー | Ctrl + C | Cmd + C |
| 貼り付け | Ctrl + V | Cmd + V |
