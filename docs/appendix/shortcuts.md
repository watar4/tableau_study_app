# ショートカット集

Tableau Desktop の主要なキーボードショートカットをまとめます。Windows と Mac で共通の操作は片方の表記のみで記載しています。

## ファイル操作

| 操作 | Windows | Mac |
|------|---------|-----|
| 新規ワークブック | Ctrl + N | Cmd + N |
| ワークブックを開く | Ctrl + O | Cmd + O |
| ワークブックを保存 | Ctrl + S | Cmd + S |
| 名前を付けて保存 | Ctrl + Shift + S | Cmd + Shift + S |
| 閉じる | Ctrl + W | Cmd + W |
| 印刷 (PDF) | Ctrl + P | Cmd + P |

## 編集操作

| 操作 | Windows | Mac |
|------|---------|-----|
| 元に戻す (Undo) | Ctrl + Z | Cmd + Z |
| やり直し (Redo) | Ctrl + Y | Cmd + Shift + Z |
| コピー | Ctrl + C | Cmd + C |
| 貼り付け | Ctrl + V | Cmd + V |
| 切り取り | Ctrl + X | Cmd + X |
| すべて選択 | Ctrl + A | Cmd + A |
| 検索と置換 | Ctrl + F | Cmd + F |

## シート操作

| 操作 | Windows | Mac |
|------|---------|-----|
| 新しいワークシート | Ctrl + M | Cmd + T |
| 新しいダッシュボード | Ctrl + Shift + M | Cmd + Shift + T |
| 新しいストーリー | Ctrl + Alt + M | Cmd + Alt + T |
| シートの複製 | Ctrl + Shift + D | Cmd + Shift + D |
| シートを削除 | Alt + F4 (タブ右クリック → 削除) | — |
| 次のシート | Ctrl + Tab | Cmd + Tab |
| 前のシート | Ctrl + Shift + Tab | Cmd + Shift + Tab |

## ビューと表示

| 操作 | Windows | Mac |
|------|---------|-----|
| プレゼンテーションモード | F7 | Cmd + . |
| 全画面表示の切替 | F11 | Cmd + Ctrl + F |
| カードの再表示 | (なし) | (右クリックメニュー) |
| 行・列を入れ替え | Ctrl + W | Cmd + Option + W |
| ビューの更新 | F5 | Cmd + R |
| カードのリセット | (なし) | (右クリックメニュー) |

## 計算フィールド

| 操作 | Windows | Mac |
|------|---------|-----|
| 計算フィールドを作成 (フィールドを右クリック → 作成 → 計算フィールド) | — | — |
| 計算エディタ内: 関数ヘルプ展開 | (右側の > ボタン) | — |
| 計算エディタ内: コミット (適用) | Ctrl + Enter | Cmd + Enter |
| 計算エディタ内: コメント追加 | `// 一行` / `/* 複数行 */` | (同) |

## マークと選択

| 操作 | Windows | Mac |
|------|---------|-----|
| マークの追加選択 (Add to selection) | Ctrl + クリック | Cmd + クリック |
| マークの範囲選択 (Range selection) | Shift + クリック | Shift + クリック |
| 選択解除 | Esc | Esc |
| すべてのマークを選択 | (ビューで Ctrl + A) | Cmd + A |
| ツールヒントを表示 | マウスオーバー | マウスオーバー |
| ラベルを表示/非表示 | (マークカードのラベルアイコン) | — |

## フィルター

| 操作 | Windows | Mac |
|------|---------|-----|
| フィルターを除外 | Shift + クリック (フィルターアイコン) | — |
| 「保持」と「除外」を切り替え | フィルターピル右クリック | — |
| クイックフィルター値を反転 | (▼メニュー → 値を反転) | — |

## ダッシュボード

| 操作 | Windows | Mac |
|------|---------|-----|
| オブジェクトの選択 | クリック | クリック |
| オブジェクトの複数選択 | Ctrl + クリック | Cmd + クリック |
| オブジェクトの削除 | Delete または Backspace | Delete |
| サイズを 1px ずつ調整 | 矢印キー | 矢印キー |
| サイズを 10px ずつ調整 | Shift + 矢印キー | Shift + 矢印キー |
| グリッドにスナップ | Shift + ドラッグ | Shift + ドラッグ |

## データソース

| 操作 | Windows | Mac |
|------|---------|-----|
| データソース画面へ移動 | (下部の「データソース」タブクリック) | — |
| シート画面へ移動 | (下部の「シート 1」タブクリック) | — |
| データソースを切り替え | F4 | — |
| 抽出/ライブの切替 | (右上「接続」セクション) | — |

## ナビゲーション

| 操作 | Windows | Mac |
|------|---------|-----|
| データペインに移動 | Ctrl + 1 | Cmd + 1 |
| アナリティクスペインに移動 | Ctrl + 2 | Cmd + 2 |
| プレゼンテーションモード | F7 | Cmd + . |
| 通常モードに戻る | Esc | Esc |

## マウスとドラッグ

| 操作 | Windows | Mac |
|------|---------|-----|
| シェルフへのフィールド配置 | ドラッグ&ドロップ | ドラッグ&ドロップ |
| フィールドを別のシェルフへ移動 | ドラッグ | ドラッグ |
| シェルフ上の集計関数を変更 | ピル右クリック → メジャー → ... | — |
| 並べ替え | 軸見出しクリック / ヘッダー上のソートアイコン | — |
| ズーム(マップ) | Shift + ドラッグ で四角選択 | — |
| パン(マップ) | Shift + ドラッグ | — |

## よく使う操作のパス

| 操作 | メニュー操作 |
|------|--------|
| パフォーマンスの記録を開始 | ヘルプ → 設定とパフォーマンス → パフォーマンスの記録を開始 |
| データソースフィルターの追加 | データソース画面 → 右上の「フィルター」 |
| 抽出フィルターの編集 | データ → [データソース名] → 抽出 → 編集 |
| Tableau Public へ公開 | サーバー → Tableau Public → ワークブックの保存 |
| アクションの追加 | ダッシュボード → アクション → アクションの追加 |
| パラメーターの作成 | データペイン右上 ▼ → パラメーターの作成 |
