# よくあるエラーと対処

学習中・業務中に遭遇しやすい Tableau Desktop のエラーと、その対処法をまとめます。

## 計算フィールド関連

### 「集計と非集計を混在できません」

**原因**: 同じ計算式の中で、集計関数 (`SUM`, `AVG` 等) と非集計フィールド (行レベルの値) を混ぜている。

```
（NG）
SUM([trip_total]) / [trip_miles]
```

`SUM([trip_total])` は集計済みだが、`[trip_miles]` は行レベル(非集計)のため混在エラーになります。

**対処**: 両方とも集計にするか、両方とも非集計にする。

```
（OK: 両方とも集計)
SUM([trip_total]) / SUM([trip_miles])

（OK: 両方とも非集計)
[trip_total] / [trip_miles]
```

非集計のままで作って、ビューに置いた段階で SUM/AVG を適用するのが一般的です。

---

### 「フィールドは集計できません」

**原因**: 文字列型・地理型・ブール型のフィールドに対して SUM や AVG を適用しようとしている。

**対処**: 計算前にフィールドを数値型に変換する。

```
INT([文字列の数字])
FLOAT([文字列の小数])
```

または、件数を数えたい場合は `COUNT()` / `COUNTD()` を使う。

---

### 「データ型が一致しません」

**原因**: 異なる型のフィールドを比較・結合しようとしている。

```
（NG）
[trip_total] = "100"   // 数値 vs 文字列
[trip_start_timestamp] > #2023-01-01#  // OK だが、文字列 "2023-01-01" だと NG
```

**対処**: 明示的な型変換を入れる。

```
[trip_total] = 100              // 数値リテラル
[trip_start_timestamp] > DATE("2023-01-01")
```

---

### 計算結果がすべて NULL になる

**原因**: 計算式の中で 1 つでも NULL を含む計算は結果も NULL になる。

```
（[tips] が NULL の場合）
[fare] + [tips]   // 結果も NULL
```

**対処**: `ZN` で NULL を 0 に置き換えるか、`IFNULL` で代替値を指定する。

```
[fare] + ZN([tips])
[fare] + IFNULL([tips], 0)
```

---

## データ接続関連

### 「データソースを開けません」

**原因**:

- ファイルパスが変わっている (移動・削除)
- ライブ接続先のデータベースが停止している
- 認証情報の期限切れ

**対処**:

1. データソースを右クリック → 「データの編集」 で新しいパスを指定
2. ライブ接続なら DB の稼働を確認
3. 「データソースのプロパティ」 → 認証情報を再入力

---

### 「クエリがタイムアウトしました」

**原因**: ライブ接続でデータソースの応答が遅すぎる。

**対処**:

- データソースの帯域を絞る (フィルターを追加して取得行数を減らす)
- ライブ接続ではなく **抽出 (.hyper)** に切り替える
- データソース側のインデックス・パーティショニングを見直してもらう

---

### Tableau Desktop が起動直後にクラッシュする

**原因**:

- Tableau Desktop バージョンと OS の互換性問題
- ライセンスファイル破損
- グラフィックドライバの不具合

**対処**:

1. Tableau 公式の対応 OS リストを確認
2. `%USERPROFILE%\Documents\My Tableau Repository\` の `Workbooks`, `Logs` 以外を退避して再起動
3. グラフィックドライバを最新化
4. 公式サポートに最新のログを添えて問い合わせ

---

## パフォーマンス関連

### ビューの描画が極端に遅い

**原因の典型**:

| パターン | 対処 |
|---------|------|
| マーク数が数万を超える | 集計レベルを上げる(月単位 → 四半期単位 等)、フィルターで絞る |
| 高基数のクイックフィルター | 「すべての値」モードに変更、または値の少ないフィールドに変更 |
| 重い計算フィールド | CASE への置換、ブール化、表計算の見直し |
| ライブ接続の重い JOIN | 抽出への切替、フィルター抽出 |

**対処**: パフォーマンスレコーダー(ヘルプ → 設定とパフォーマンス → パフォーマンスの記録を開始)で原因を特定。

---

### Tableau Desktop がフリーズする / 「応答なし」

**原因**:

- 大量のマーク描画(数百万マークなど)
- メモリ不足
- LOD のネストや巨大ピボット

**対処**:

1. 抽出データのサイズを確認 (100MB 程度を超えると重くなりがち)
2. ビューに必要のないフィールドを「詳細」シェルフから外す
3. シートを 1 つずつ無効化 (右クリック → 「シートを除外」) して原因シートを特定

---

## 公開・共有関連

### Tableau Public へ公開できない

**原因**:

- Tableau Public アカウントが未認証
- データソースに **ライブ接続** が含まれている (Public は抽出のみ対応)
- ワークブックサイズが上限超過 (15 GB)

**対処**:

1. ライブ接続を **抽出** に切り替える
2. データソース → 「ファイル」 → 「データの抽出」
3. 「サーバー」 → 「Tableau Public」 → 「ワークブックの保存」 を再実行

---

### `.twbx` を開くとデータが見つからないと表示される

**原因**: `.twbx` は本来データを内包しますが、生成時にデータ参照が外れているケース。

**対処**: 元のファイルを開き、データソースが正しく抽出されているか確認 → 抽出を作成し直して `.twbx` で再保存。

---

### Tableau Public の埋め込みが Web サイトで表示されない

**原因**:

- 埋め込み先サイトが HTTPS だが iframe の URL が HTTP
- iframe のサイズが小さすぎる
- 公開設定で「ダウンロード許可」と「シェア許可」が無効化

**対処**:

1. iframe URL を `https://public.tableau.com/...` に統一
2. 幅と高さに十分なピクセルを指定 (1000 × 700 以上が目安)
3. Tableau Public 上の公開設定を確認

---

## BigQuery / 外部 DB 接続関連

### BigQuery 認証エラー

**原因**:

- 認証情報の期限切れ (OAuth は通常 1 時間で失効)
- サービスアカウント JSON キーのパス間違い
- BigQuery API が有効化されていない

**対処**:

1. メニュー「データ」 → データソース名 → 「データの編集」 → 認証を再実行
2. サービスアカウントの場合は GCP コンソールで API 有効化と権限(BigQuery Data Viewer 以上) を確認
3. プロジェクトの請求アカウントが有効か確認

---

### BigQuery クエリの月額料金が想定より高い

**原因**: ライブ接続でフィルターを動かすたびに毎回スキャンが走り、課金が積み上がっている。

**対処**:

- **抽出 (.hyper) に切り替える** (本ツールではこの方針)
- 抽出の更新を 1 日 1 回などのスケジュールに限定
- BigQuery 側のテーブルをパーティション化して スキャン量を削減

---

## その他の典型エラー

### 「ファイルを開けません: バージョンが新しすぎます」

**原因**: 新しい Tableau Desktop で作ったファイルを古いバージョンで開こうとしている。

**対処**: ファイル → 「以前のバージョンとしてエクスポート」 → 開きたい側のバージョンを指定して保存。

---

### 「日本語が文字化けする」

**原因**: CSV ファイルのエンコーディングが Shift-JIS だが、Tableau が UTF-8 として読んでいる(またはその逆)。

**対処**: テキストエディタで CSV を UTF-8 (BOM 付き) で保存し直してから再接続。

---

### 「マップが表示されない」

**原因**:

- 地理的役割が設定されていない
- インターネット接続なし(マップタイルが取得できない)
- 緯度/経度の値が範囲外

**対処**:

1. フィールドを右クリック → 「地理的役割」 → 「緯度」「経度」「市区町村」等を割り当て
2. ネットワーク疎通を確認
3. 緯度: -90〜90、経度: -180〜180 の範囲を確認

---
