## 1. ファイル形式

Tableau のファイル形式は用途に応じて 5 種類あります。混同しやすいので最初に整理しておきましょう。

| 拡張子 | 内容 | データを含む | 用途 |
|--------|------|--------------|------|
| `.twb` | ワークブック定義のみ（XML） | 含まない | バージョン管理。ライブ接続のみ |
| `.twbx` | ワークブック + 抽出 + 同梱アセット（パッケージ） | 含む | 配布・共有・Tableau Public 公開 |
| `.hyper` | データ抽出ファイル単体 | 含む（データ本体） | 抽出データの受け渡し |
| `.tds` | データソース定義のみ | 含まない | データソース定義の再利用 |
| `.tdsx` | データソース定義 + 抽出のパッケージ | 含む | 抽出付きデータソースの配布 |

### 書き出し方

メニュー「**ファイル**」 → 「**エクスポート済みパッケージドワークブック**」（または「**名前を付けて保存**」） → 拡張子を選択。

- 開発者間でデータベース接続が共有されているなら `.twb` でも十分
- 環境を持たない相手に配るなら `.twbx`
- データソースの再利用（接続情報とデータ準備）が目的なら `.tdsx`

::: warning パッケージドワークブックの中身
`.twbx` は実体としては ZIP ファイルです。拡張子を `.zip` に変えて展開すれば、中の `.twb` と `.hyper` を取り出せます。「データを社外に出してはいけない」案件で `.twbx` を配ると、データを抜き取られる可能性がある点に注意してください。
:::

## 2. Tableau Public への公開手順

**Tableau Public** は、無料で利用できるクラウドサービスです。作ったダッシュボードを Web 上で誰でも閲覧できるように公開できます。

### 事前準備

1. Tableau Public のアカウントを作成（https://public.tableau.com/）
2. Tableau Desktop または Tableau Public 版のアプリをインストール

### 公開手順

1. ワークブックを開いた状態でメニュー「**サーバー**」 → 「**Tableau Public**」 → 「**ワークブックの保存**」を選択（Tableau Public 版アプリの場合は「**ファイル**」メニューにある場合もあります）
2. Tableau Public アカウントのメールアドレスとパスワードでサインイン
3. ワークブック名を入力
4. アップロードが完了すると、自動でブラウザが開き公開ページが表示される

![Tableau Public へのサインインダイアログ](/images/17-publish/public-sign-in.png)

### 公開後にできること

- 公開 URL を共有（誰でも閲覧可能）
- 公開ページの「シェア」ボタンから iframe 埋め込みコードを取得し、自分のブログや Web サイトに埋め込み
- 自分のプロフィールページに作品集として並べる
- 閲覧者がワークブックをダウンロードできる（許可するかは公開設定で制御）

::: info Tableau Public は「すべて公開」
Tableau Public にアップロードしたデータは原則すべて誰でも閲覧・ダウンロードできます。社内データや個人情報は絶対にアップロードしないでください。
:::

## 3. 公開時の注意

公開する前に、以下のチェックを必ず行いましょう。

### 機微情報の確認

- 個人を特定できる情報（氏名、メール、電話番号、社員ID 等）が含まれていないか
- 社内の財務データ・顧客リストが入っていないか
- 取引先名や案件名など、契約上開示できない情報がないか

### データ利用ライセンスの確認

- データの出所が公開・再配布可能なライセンスか確認（Creative Commons、政府オープンデータなど）
- 商用データを Tableau Public で再公開するのはほぼ NG
- 出典・ライセンス表記をダッシュボードに明示

### ワークブック内のクリーンアップ

| チェック項目 | 内容 |
|--------------|------|
| 未使用のシート | 「下書き」「テスト」のような不要シートを削除 |
| 一時的な計算フィールド | `tmp_` プレフィックスのものを削除 |
| ツールヒントの個人情報 | 元データに残っていないか確認 |
| カラム名 | 内部呼称ではなく閲覧者が理解できる名前にリネーム |
| シートタイトル・キャプション | 抜けがないかチェック |
| データソース名 | 「DB1_dev」のような社内的な名前から汎用名へ |

::: warning 一度公開した内容は記録に残る
公開後に削除しても、ダウンロード済みの利用者には残ります。「公開ボタンを押す前」が最後のチェックチャンスです。
:::

## 4. Tableau Cloud / Server（概要のみ）

業務でダッシュボードを共有する場合、Tableau Public ではなく **Tableau Cloud** または **Tableau Server** を使うのが一般的です。

| 製品 | 提供形態 | 主な特徴 |
|------|----------|----------|
| **Tableau Public** | クラウド（無料） | 誰でも閲覧可。データも公開される |
| **Tableau Cloud** | クラウド（SaaS） | Tableau 社が運営。社内認証で閲覧範囲を制御可。アップデート自動 |
| **Tableau Server** | オンプレ / 自社クラウド | 自社で運用・管理。社内ネットワーク内で完結 |

### Cloud と Server の主な違い

| 観点 | Tableau Cloud | Tableau Server |
|------|---------------|----------------|
| 運用主体 | Tableau 社 | 自社（IT 部門） |
| ハードウェア | 不要 | 自社で用意 |
| バージョン管理 | 自動アップデート | 自社の都合で計画的に更新 |
| データ所在 | 外部（クラウド） | 自社管理下 |
| 機微データの扱い | 規程・契約次第 | 社内ネットワーク内なら扱いやすい |
| 初期コスト | 低い（サブスク） | 高め（インフラ） |
| 拡張性 | 自動でスケール | 自社で増強 |

### 機能の共通点

- ユーザー認証・権限管理（プロジェクト/ロール）
- 抽出の自動更新スケジュール
- データソース・ワークブックの集中管理
- 行レベルセキュリティ
- サブスクリプション（定期レポート配信）
- アラート通知

::: info 使い分けの目安
社内データを社外クラウドに置くことが許されない場合は Server、許される場合はインフラ運用負荷の小さい Cloud が選ばれることが多いです。最近は Cloud への移行が主流ですが、業界・地域・データ機密度によって判断は変わります。
:::

## 5. PDF / 画像エクスポート / プレゼンテーションモード

ダッシュボードを Tableau の外で見せたい場合の選択肢です。

### PDF エクスポート

メニュー「**ファイル**」 → 「**PDF の印刷**」（環境により表記が異なる場合があります）。

- 用紙サイズ、向き、シート範囲（現在のビュー / 選択 / ブック全体）を指定
- 1 シート = 1 ページ、複数シートを 1 ページに収めるなどの調整が可能
- 印刷向けの定型レポートに最適

### 画像エクスポート

メニュー「**ワークシート**」 → 「**エクスポート**」 → 「**画像**」、または「**コピー**」 → 「**画像**」。

- PNG / JPG 形式で保存
- スライド資料・Word ドキュメントに貼り付けて使う

### クロス集計のエクスポート

メニュー「**ワークシート**」 → 「**エクスポート**」 → 「**クロス集計を Excel に**」。

- ビューの値をそのまま Excel に出力
- 「ピボット形式での出力」で受け渡し用のクロス集計が作れる

### プレゼンテーションモード

ツールバーまたは F7 キーで起動できる**プレゼンテーションモード**は、Tableau の編集 UI を隠して、ダッシュボード/ストーリーだけをフルスクリーン表示します。

- 社内会議でそのままダッシュボードを見せたいとき
- ライブで触りながら説明したいとき
- 編集メニューやデータペインが映ると説明の邪魔になるとき

![プレゼンテーションモードに切り替えたダッシュボード](/images/17-publish/presentation-mode.png)

::: tip 静的レポート vs インタラクティブ共有
- 「読むだけで終わる」資料なら PDF / 画像 / Excel エクスポートが楽
- フィルター操作やドリルダウンを使ってほしいなら Tableau Public / Cloud / Server に公開

目的に応じて使い分けてください。
:::

## やってみよう

Chicago Taxi のダッシュボードを Tableau Public に公開します。事前に Tableau Public のアカウントを作成しておいてください。

1. **公開前チェック**
   - 未使用シートを削除、未使用計算を整理、シート名・タイトルをリネーム。
2. **データソース名の確認**
   - 「Chicago Taxi 2023 サンプル」のような閲覧者が分かる名前に変更。
3. **`.twbx` 形式で別名保存**
   - メニュー「ファイル」 → 「名前を付けて保存」 → ファイル形式に「.twbx」を選び、ローカルにバックアップ。
4. **Tableau Public へサインイン**
   - メニュー「サーバー」 → 「Tableau Public」 → 「Tableau Public にサインイン」でメールアドレスとパスワードを入力。
5. **アップロード**
   - 「サーバー」 → 「Tableau Public」 → 「ワークブックの保存」 → ワークブック名を入力 → 「保存」。
6. **公開ページを確認**
   - ブラウザが自動で開く。「シェア」ボタンを開き、リンクと埋め込みコードを取得。
7. **PDF エクスポート**
   - メニュー「ファイル」 → 「PDF の印刷」で印刷向けの PDF を出力。
8. **プレゼンテーションモード**
   - F7 を押してフルスクリーン表示。Esc で戻ることを確認。

## まとめ

- ファイル形式は **.twb / .twbx / .hyper / .tds / .tdsx** の 5 種類。配布には主に **.twbx** を使います。
- **Tableau Public** は無料で利用可ですが、データもすべて公開されるため、機微情報の混入には細心の注意が必要です。
- 業務利用は **Tableau Cloud（SaaS）** または **Tableau Server（オンプレ）** が選択肢で、データの所在・運用主体・コスト構造が異なります。
- 公開前には「機微情報」「ライセンス」「未使用オブジェクト」のチェックリストを必ず通しましょう。
- 静的共有は PDF / 画像 / Excel エクスポート、プレゼンには F7 のプレゼンテーションモードが便利です。
