## 1. パラメーターとは（定数の差し替え）

**パラメーター**は「ユーザーが値を選んで差し替えられる定数」のことです。計算フィールドの中に直接「100」と書いてしまうと、その値を変えるたびに計算式を編集する必要があります。代わりにパラメーター `[しきい値]` を使えば、ダッシュボード上のコントロール（ドロップダウンやスライダー）で値を切り替えられるようになります。

パラメーターはデータソースには依存しないグローバルな値です。1 つのワークブックの中であれば、複数のシート・計算・フィルター・参照線などから同じパラメーターを参照できます。

| 概念 | パラメーター | フィルター |
|------|--------------|------------|
| 値の出所 | ユーザーが選ぶ単一の値 | データの値 |
| 影響範囲 | 計算式やタイトルから参照する箇所すべて | フィルター対象のビュー |
| 単一/複数値 | 単一値のみ | 複数値も可 |
| データソース依存 | しない | する |

::: tip パラメーターは「単一値」
パラメーターが保持できるのは常に 1 つの値です。「複数選択させたい」場合はセットやフィルターを使うのが基本です。
:::

## 2. パラメーターの作成（型・許容値・表示形式）

データペインの右上にあるドロップダウン（▼）から「**パラメーターの作成**」を選びます。ダイアログで以下を指定します。

| 項目 | 内容 |
|------|------|
| **名前** | データペインに表示される名称 |
| **データ型** | 整数 / 浮動小数点 / 文字列 / ブール / 日付 / 日付と時刻 |
| **現在の値** | 初期値 |
| **表示形式** | 数値の桁区切り、通貨、パーセント、日付形式など |
| **許容値** | すべて / リスト / 範囲 |

### 許容値の 3 種類

- **すべて**: 任意の値を入力可能（テキストボックス）
- **リスト**: あらかじめ定義した選択肢から選ぶ。「フィールドから追加」でデータの値を流用できる
- **範囲**: 数値や日付の最小値・最大値・刻み幅を指定し、スライダーで選ばせる

![パラメーター作成ダイアログ（リスト型）](/images/13-parameters-sets/parameter-dialog.png)

::: info パラメーターコントロールの表示
作成したパラメーターをデータペインで右クリック → 「**パラメーターの表示**」でビュー右側にコントロールが表示されます。ダッシュボードに配置するときも同様に「パラメーター」オブジェクトとして追加します。
:::

## 3. パラメーターを計算/フィルター/参照線に使う

パラメーターは以下のような場所から参照できます。

### 計算フィールドで使う

たとえば「料金がしきい値を超えるかどうか」を返すブールを作る場合。

```
[trip_total] >= [しきい値]
```

`[しきい値]` をスライダーで動かすと、計算結果が再評価されてビューが更新されます。

### TOP N フィルターの N に使う

フィルターのダイアログで「上位」タブを開き、N の値にパラメーター `[上位N]` を指定すると、ユーザーが TOP5 / TOP10 / TOP20 を切り替えられるようになります。

### 参照線の値に使う

ビューの軸を右クリック → 「リファレンスラインの追加」 → 値にパラメーター `[目標売上]` を指定します。これで目標値をユーザー側で動かせるようになります。

### シートタイトルに埋め込む

タイトルや注釈の編集画面で「**挿入**」 → 「**パラメーター**」を選ぶと、現在のパラメーター値が動的にタイトルに反映されます。

![参照線にパラメーターを使った棒グラフ](/images/13-parameters-sets/parameter-reference-line.png)

::: tip 「メジャー切替」テクニック
パラメーターを文字列リスト型にして「売上」「乗車回数」「平均距離」などの選択肢を持たせ、計算フィールドで `CASE [指標切替] WHEN "売上" THEN [trip_total] ... END` のように分岐させると、ユーザーが見たい指標を切り替えられるダッシュボードが作れます。
:::

## 4. パラメーターアクション（ユーザー操作で値を変える）

通常のパラメーターは「ユーザーがドロップダウンやスライダーで自分で値を変える」ものですが、**パラメーターアクション**を使うと「ビュー上でマークをクリックしただけでパラメーター値を変える」ことができます。

ダッシュボード（またはワークシート）のメニューから「**アクション**」 → 「**アクションの追加**」 → 「**パラメーターの変更**」を選びます。

| 設定項目 | 内容 |
|----------|------|
| ソースシート | クリックを受け付けるシート |
| 対象パラメーター | 値を書き換えるパラメーター |
| ソースフィールド | クリックされたマークのどのフィールドの値を使うか |
| 集計 | フィールドが集計済みなら指定 |

たとえば「会社別の棒グラフをクリックすると、その会社名がパラメーターに入って、別シートの計算が再評価される」といった連動が作れます。

::: info パラメーターアクションは Tableau 2019.2 以降
古いバージョンを共有相手が使っている場合は注意してください。
:::

## 5. セット（固定セット / 計算セット / 動的セットアクション）

**セット**は「あるディメンションの値の部分集合」を保存したものです。「お気に入りの会社 10 社」「上位 20% の乗車エリア」のように、メンバーをグループ化して取り回せます。

### 3 つの作り方

| 種類 | 作り方 | 用途 |
|------|--------|------|
| **固定セット** | ビュー上で複数マークを選択 → 右クリック → 「セットの作成」 | 任意に手で選んだメンバー |
| **計算セット（条件 / 上位）** | ディメンションを右クリック → 「作成」 → 「セット」 → 「条件」または「上位」タブ | 「売上 100万 以上」「TOP10 会社」など、条件に合うメンバー |
| **動的セットアクション** | アクションメニューから「セット値の変更」 | ユーザーのクリックでメンバーを変える |

![セット作成ダイアログ（条件タブ）](/images/13-parameters-sets/set-condition.png)

### セットとグループの違い

| 観点 | セット | グループ |
|------|--------|----------|
| メンバーシップ | IN / OUT の 2 値 | 任意の数のカテゴリ |
| 動的更新 | 条件式や上位 N に応じて自動更新 | 手動 |
| 計算からの参照 | `[セット名]` がブールとして使える | `[グループ名]` がディメンションとして使える |

## 6. IN / OUT セット計算

セットはビューにそのままドラッグすると「**イン/アウト**」の 2 値ディメンションとして機能します。「セットに含まれるメンバーの売上」と「含まれないメンバーの売上」を 2 本の棒で比較する、といった可視化に向きます。

計算フィールドでもブールとして扱えます。

```
IF [上位10社セット] THEN [trip_total] ELSE 0 END
```

これで「上位 10 社の売上だけを合計する」メジャーが作れます。

### 動的セットアクションでドリルダウン

ダッシュボードで「会社別の棒グラフ」をクリックすると、選んだ会社が「対象セット」に入り、別のシートではセットメンバーだけの詳細が表示される、といった対話的なドリルダウンを作れます。

::: tip 「セットからの分離」
ビュー上のセットメンバー（IN 側のマーク）を右クリックして「**セットから削除**」、または OUT 側のマークから「**セットに追加**」で、固定セットのメンバーをその場で編集できます。
:::

## 7. ビン（固定幅 / 変動幅）

**ビン**は連続値を一定の幅で区切り、離散カテゴリに変えたものです。度数分布（ヒストグラム）の作成に欠かせません。

### 固定幅ビン

メジャーを右クリック → 「作成」 → 「ビン」を選び、**ビンのサイズ**（幅）を指定します。たとえば `trip_miles` を「2 マイル幅」のビンにすれば、0–2 / 2–4 / 4–6 …という区間ができます。

ビンはデータペインに「`[trip_miles] (ビン)`」のような新しいディメンションとして追加されます。作成後でも該当ビンを右クリック →「**編集**」でサイズを変更できるので、後から幅を変えたい場合も再作成する必要はありません。

### ヒストグラムを作る

1. ビンを列にドラッグ
2. 元のメジャー（または `COUNT([trip_id])`）を行にドラッグ
3. マークタイプは「棒」を選択

これで度数分布が描けます。

![trip_miles の度数分布（ヒストグラム）](/images/13-parameters-sets/histogram.png)

### 変動幅ビン（パラメーター連動）

ビンの「サイズ」にパラメーターを指定すると、ユーザーが幅を動かすたびにヒストグラムの粒度が変わります。「データの分布を粗く見るか細かく見るか」をインタラクティブに切り替えたいときに便利です。

::: warning ビンは数値・日付のみ
文字列ディメンションに対してビンは作れません。文字列をカテゴリ化したい場合はグループや計算フィールドを使います。
:::

## やってみよう

Chicago Taxi データで、パラメーター・セット・ビンを一通り体験します。

1. **しきい値パラメーターを作成**
   - データペインから「パラメーターの作成」 → 名前「料金しきい値」、データ型「浮動小数点」、許容値「範囲」（最小 0、最大 100、刻み 5）。
2. **しきい値超え判定の計算フィールド**
   - `[しきい値超え] = [trip_total] >= [料金しきい値]` を作成。
3. **ビューで使う**
   - `company` を行、`SUM(trip_total)` を列にドラッグ。`[しきい値超え]` を色に置く。パラメーターコントロールを表示してスライダーを動かす。
4. **TOP N 会社の動的セットを作成**
   - `company` を右クリック → 「作成」 → 「セット」 → 「上位」タブで「フィールド: `SUM(trip_total)`、上位 10 件」を指定し、「上位10社セット」と命名。
5. **IN/OUT の比較ビュー**
   - 新しいシートで「上位10社セット」を列に置き、`SUM(trip_total)` を行にドラッグ。「上位 10 社 vs それ以外」の比較棒グラフが完成。
6. **trip_miles のヒストグラム**
   - `trip_miles` を右クリック → 「作成」 → 「ビン」、サイズを 2 にして「距離ビン」を作成。列に距離ビン、行に `COUNT([trip_id])` を置く。
7. **ビン幅をパラメーター連動に**
   - パラメーター「ビン幅」を作成し、距離ビンの編集ダイアログでサイズにパラメーターを指定。コントロールから幅を切り替える。
8. **タイトルにパラメーター値を埋め込む**
   - シートのタイトルを編集し、「挿入」 → 「パラメーター」で `[料金しきい値]` を埋め込む。タイトルが「料金 〇〇 ドル以上の集計」のように動的になることを確認。

---

## まとめ

- **パラメーター**は単一値のユーザー入力で、計算/フィルター/参照線/タイトルから自由に参照できます。
- **パラメーターアクション**はビュー上のクリックでパラメーター値を書き換える仕組みで、対話的なダッシュボードに不可欠です。
- **セット**は「ディメンションメンバーの部分集合」で、固定/条件/上位/動的 の 4 種類の作り方があります。
- セットはビューでは IN/OUT の 2 値、計算フィールド内ではブールとして扱えます。
- **ビン**は連続値を区切って度数分布（ヒストグラム）を作るための仕組みで、パラメーターと組み合わせると幅を動かせます。
