## 1. Tableau の世界観（VizQL の発想）

Tableau の中核には **VizQL (Visual Query Language)** という考え方があります。これは「画面上のドラッグ&ドロップ操作を、そのままデータベースへのクエリに変換する」という仕組みです。

- フィールドをビューに配置するたびに、Tableau は裏側でクエリを発行し、その結果をすぐにグラフとして描画します。
- ユーザーは SQL を書く必要がなく、「見たい形をビューで指定する」だけで結果が得られます。
- 試行錯誤のコストが非常に低いため、データ探索の段階で大きな威力を発揮します。

::: tip Excel ピボットテーブルとの違い
Excel のピボットテーブルは「表」が主役で、グラフは表をもとに後から作るオブジェクトです。Tableau は「ビュー（グラフ）」が一級市民で、表もまたビューの一形態として扱われます。
:::

## 2. ディメンションとメジャー

Tableau の最も基本的な区別が **ディメンション** と **メジャー** です。

| 区分 | 役割 | 例（Chicago Taxi データ） |
|------|------|----------------------------|
| ディメンション (Dimension) | 質的データ。集計の「**軸**」になる | `company`（タクシー会社）、`payment_type`（支払方法）、`pickup_community_area`（乗車エリア） |
| メジャー (Measure) | 量的データ。集計の「**対象**」になる | `trip_total`（料金）、`trip_miles`（距離）、`trip_seconds`（乗車時間） |

データに接続すると、Tableau はフィールドの型をもとに自動でディメンション/メジャーに振り分けます。データペインの**上半分がディメンション**、**下半分がメジャー**です。

  <span class="img-placeholder-caption">ディメンションとメジャーのペイン</span>
  <span class="img-placeholder-path">docs/public/images/01-basics/dim-measure-pane.png</span>
</div>

### 自動判定を上書きする

数値型でもディメンションとして扱いたい場合があります。たとえば `pickup_community_area` は数値ですが「エリアの識別子」なので、メジャーとして合計したり平均したりする意味はありません。

- フィールドを右クリック → 「ディメンションに変換」
- 逆にディメンションをメジャーとして集計したい場合は「メジャーに変換」

### よくある勘違い

- 「ディメンション = 文字列、メジャー = 数値」は **おおむね正しいが絶対ではない**
- 日付フィールドはデフォルトでディメンションになります
- ID 列のような数値はメジャーとして自動分類されることがあり、明示的にディメンションへ移します

## 3. 連続（緑）と不連続（青）

ディメンション/メジャーとは **独立した** もう一つの軸が、**連続 (Continuous) / 不連続 (Discrete)** です。色で区別され、

- **青 = 不連続**: 個々の値として扱う。ビューに置くと「**ヘッダー**」が作られる。色はカラーパレット（離散色）
- **緑 = 連続**: 範囲を持つ値として扱う。ビューに置くと「**軸**」が作られる。色はグラデーション

を意味します。

<div class="img-placeholder">
  <span class="img-placeholder-tag">画像予定</span>
  <span class="img-placeholder-caption">緑(連続/軸) と 青(不連続/ヘッダー) の見た目比較</span>
  <span class="img-placeholder-path">docs/public/images/01-basics/green-vs-blue.png</span>
</div>

### 4 つの組み合わせ

|  | 不連続（青） | 連続（緑） |
|---|---|---|
| **ディメンション** | デフォルト。例: `company` をヘッダー表示 | 例: `pickup_community_area` を「数値の連続」として軸表示 |
| **メジャー** | 例: `SUM(trip_total)` をヘッダー（=表形式）で表示 | デフォルト。例: `SUM(trip_total)` を軸として表示 |

### 切替方法

フィールドを右クリックして「**連続**」/「**不連続**」を選択します。日付フィールドではこの切替が特に重要で、たとえば「2024-04」を不連続として扱えば「ラベル」、連続として扱えば「時間軸」になります。

::: info メジャーは必ず緑ではない
メジャーはデフォルトで緑（連続）ですが、不連続に変換することもできます。たとえば「年ごとに 1 行のクロス集計表を作りたい」ときは、`SUM(trip_total)` を不連続にしてラベル化します。
:::

## 4. シェルフ（行・列・フィルター・ページ）

ビューを組み立てる場所が **シェルフ** です。

<div class="img-placeholder">
  <span class="img-placeholder-tag">画像予定</span>
  <span class="img-placeholder-caption">列・行・フィルター・ページのシェルフ</span>
  <span class="img-placeholder-path">docs/public/images/01-basics/shelves.png</span>
</div>

| シェルフ | 役割 |
|---------|------|
| **列 (Columns)** | X 軸を担当 |
| **行 (Rows)** | Y 軸を担当 |
| **フィルター (Filters)** | 表示するデータの絞り込み |
| **ページ (Pages)** | ページごとにフレームを分割し、アニメーション再生できる |

行・列にフィールドをドラッグして配置すれば、それだけでビューが生成されます。何度でも入れ替えながら最適な形を探せるのが Tableau の強みです。

## 5. マークカード

行・列で「どこに置くか」を決め、**マークカード**で「どう見せるか」を決めます。

<div class="img-placeholder">
  <span class="img-placeholder-tag">画像予定</span>
  <span class="img-placeholder-caption">マークカード 6 シェルフの全景</span>
  <span class="img-placeholder-path">docs/public/images/01-basics/mark-card.png</span>
</div>

| シェルフ | 役割 | 使用例 |
|---------|------|-------|
| **マークタイプ** | 自動 / 棒 / 線 / 円 / 形状 / マップ など | 折れ線にしたいときに「線」を選ぶ |
| **色 (Color)** | ディメンションなら系列色、メジャーならグラデーション | `payment_type` を色にドラッグ → 支払方法ごとに色分け |
| **サイズ (Size)** | マークの大きさ | バブルチャートで件数を表現 |
| **ラベル (Label)** | データラベルの表示 | 各マークの値を数字で表示 |
| **詳細 (Detail)** | **ビューに表示せず、集計粒度を細かくする** | ビューには会社別の合計だけ表示しつつ、内部的には日別の粒度で計算したい場合に使用 |
| **ツールヒント (Tooltip)** | マウスオーバー時に表示する内容 | 補足情報を持たせる |
| **形状 (Shape)** | マークタイプが「形状」のときのみ有効 | データ型ごとに ▲ ● ■ など |

::: tip 「詳細」が重要
詳細シェルフは見落とされがちですが、Tableau で集計粒度を細かく制御する基本道具です。たとえば「会社別の合計売上を棒グラフで見せつつ、ツールヒントには日別の内訳を出したい」場合、ツールヒントだけでは粒度が足りないので、日付フィールドを詳細に追加して粒度を確保します。
:::

## 6. データペイン / アナリティクスペイン

左サイドバーには 2 つのタブがあります。

### データペイン

接続したデータのフィールド一覧です。上半分がディメンション、下半分がメジャーで、計算フィールドやパラメーター、セットなどもここに集約されます。検索ボックスやフォルダ機能を使って整理します。

### アナリティクスペイン

ビューに **分析オブジェクト**（平均線、中央値線、トレンドライン、予測、ボックスプロット、参照分布、クラスター など）を **ドラッグで追加** するためのパネルです。

たとえば散布図にトレンドラインを引きたい場合、アナリティクスペインの「トレンドライン」をビューにドラッグするだけで追加できます。

## 7. ワークブック構造

Tableau のファイルは階層構造を持ちます。

```
データソース (接続情報 + 抽出 + データ準備)
  └─ ワークブック (.twb / .twbx)
       ├─ ワークシート (1つのビュー)
       ├─ ワークシート
       ├─ ダッシュボード (複数シート + テキスト/画像/Web の組み合わせ画面)
       └─ ストーリー (シートやダッシュボードを並べたプレゼン形式)
```

![データソース 〜 ストーリーの階層図](/images/01-basics/workbook-structure.png)

### ファイル形式

| 拡張子 | 内容 |
|-------|------|
| `.twb` | ワークブック定義のみ（XML、抽出を含まない） |
| `.twbx` | ワークブック定義 + 抽出 + 同梱アセットをまとめたパッケージ |
| `.hyper` | データ抽出ファイル（Tableau の独自フォーマット） |
| `.tds` | データソース定義のみ |
| `.tdsx` | データソース定義 + 抽出のパッケージ |

::: warning .twb と .twbx を混同しない
他の人に共有する場合、データを含まない `.twb` を渡してもデータソースが手元になければ開けません。共有用には `.twbx` を使用するのが基本です。詳細は 17 章で扱います。
:::

## やってみよう

同梱の `chicago_taxi_trips.hyper` を使って、本章の概念を一通り触ってみましょう。

1. **データに接続**
   - Tableau Desktop を起動 → 「データに接続」 → 「その他のファイル」 → `chicago_taxi_trips.hyper` を選択
   - 接続できたら左下の `Sheet 1` をクリックしてワークシートに移動します。
2. **ディメンションとメジャーを確認**
   - データペインを開き、`company` がディメンション側、`trip_total` がメジャー側にあることを確認します。
3. **棒グラフを作る**
   - `company` を「列」、`trip_total` を「行」にドラッグします。自動で棒グラフが生成されます。
4. **色をつけて連続/不連続を試す**
   - `trip_total` をマークカードの「色」にドラッグ → 連続グラデーションになります。
   - `payment_type` を「色」にドラッグし直す → 不連続のカラーパレットになります。
5. **メジャーを不連続に変える**
   - 行シェルフの `SUM(trip_total)` を右クリック → 「不連続」を選択 → ヘッダー表示に変化することを確認します。
6. **アナリティクスペインで平均線を引く**
   - 左サイドバーの「アナリティクス」タブを開き、「平均線」をビューにドラッグします。

---

## まとめ

- Tableau は VizQL によって、ドラッグ&ドロップ操作を裏側のクエリへ変換します。
- データには **ディメンション** と **メジャー** の役割があり、独立して **連続（緑）/ 不連続（青）** という属性も持ちます。
- ビューは **シェルフ** で構造を決め、**マークカード** で見た目を決めます。
- 左サイドバーには、フィールド一覧の **データペイン** と、分析オブジェクトを追加する **アナリティクスペイン** があります。
- ファイルは「データソース → ワークブック → シート → ダッシュボード → ストーリー」という階層構造です。
