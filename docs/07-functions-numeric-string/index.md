## 1. 数値関数

Tableau には数値計算用の関数が一通り揃っています。表計算ソフトと同じ感覚で使えるものがほとんどですが、戻り型と引数順序には注意が必要です。

### 丸め・絶対値・符号

| 関数 | 説明 | 例 | 結果 |
|------|------|----|------|
| `ABS(数値)` | 絶対値 | `ABS(-3.5)` | `3.5` |
| `ROUND(数値, [桁])` | 四捨五入。第2引数は省略可（0扱い） | `ROUND(2.345, 2)` | `2.35`（環境により `2.34` の場合あり） |
| `CEILING(数値)` | 切り上げ（整数） | `CEILING(2.1)` | `3` |
| `FLOOR(数値)` | 切り捨て（整数） | `FLOOR(2.9)` | `2` |
| `SIGN(数値)` | 符号 (-1 / 0 / 1) | `SIGN(-5)` | `-1` |

```
// マイル単価を小数第2位で丸める
ROUND([fare] / [trip_miles], 2)
```

```
// 距離の絶対値（負の値が混入していたケースの保険）
ABS([trip_miles])
```

::: info ROUND の挙動
`ROUND` は接続するデータソースによっては、銀行家丸め（偶数丸め）になることがあります。厳密な四捨五入が必要なら `FLOOR(x * 100 + 0.5) / 100` のような自前実装も検討します。
:::

### 整数除算・剰余

| 関数 | 説明 | 例 | 結果 |
|------|------|----|------|
| `DIV(整数, 整数)` | 整数除算（商） | `DIV(10, 3)` | `3` |
| `MOD(整数, 整数)` | 剰余 | `MOD(10, 3)` | `1` |

```
// 乗車時間を「分:秒」の形にしたい場合の素材
DIV([trip_seconds], 60)   // 分
MOD([trip_seconds], 60)   // 秒
```

### 累乗・対数・指数・平方根

| 関数 | 説明 | 例 |
|------|------|----|
| `POWER(底, 指数)` | べき乗（`^` と同じ） | `POWER(2, 10)` → `1024` |
| `EXP(数値)` | e の x 乗 | `EXP(1)` → `2.718...` |
| `LN(数値)` | 自然対数 | `LN(2.718)` → `≒1` |
| `LOG(数値, [底])` | 対数。底省略時は 10 | `LOG(1000)` → `3` |
| `SQRT(数値)` | 平方根 | `SQRT(16)` → `4` |
| `SQUARE(数値)` | 二乗 | `SQUARE(5)` → `25` |

```
// 距離を対数スケールで表示用に変換
LOG([trip_miles] + 1)
```

### 最小・最大（行レベル）

| 関数 | 説明 | 例 |
|------|------|----|
| `MIN(値1, 値2)` | 2引数の小さい方（行レベル） | `MIN([fare], 100)` |
| `MAX(値1, 値2)` | 2引数の大きい方（行レベル） | `MAX([fare], 5)` |

::: warning 集計関数の MIN/MAX と区別する
`MIN([fare])` のように 1 引数で使うと集計関数（フィールド全体の最小値）になります。2 引数で使えば行レベルの「2 つのうち小さい方」です。Tableau は引数の数で挙動を切り替えます。
:::

```
// 最低料金 5 ドルを保証（5 ドル未満は 5 に底上げ）
MAX([fare], 5)
```

## 2. 文字列関数（基本）

### 取り出し・長さ

| 関数 | 説明 | 例 | 結果 |
|------|------|----|------|
| `LEFT(文字列, n)` | 先頭 n 文字 | `LEFT("Chicago", 4)` | `"Chic"` |
| `RIGHT(文字列, n)` | 末尾 n 文字 | `RIGHT("Chicago", 3)` | `"ago"` |
| `MID(文字列, 開始, [n])` | 中間。開始位置は 1 始まり | `MID("Chicago", 2, 3)` | `"hic"` |
| `LEN(文字列)` | 文字数 | `LEN("Chicago")` | `7` |

```
// company の先頭 4 文字をコードとして抽出
LEFT([company], 4)
```

### 検索・判定

| 関数 | 説明 | 例 | 結果 |
|------|------|----|------|
| `FIND(対象, 検索, [開始])` | 位置を返す。見つからなければ 0 | `FIND("Chicago", "ica")` | `3` |
| `CONTAINS(対象, 検索)` | 部分一致を真偽で返す | `CONTAINS("Chicago", "ica")` | `true` |
| `STARTSWITH(対象, 検索)` | 前方一致 | `STARTSWITH("Chicago", "Chi")` | `true` |
| `ENDSWITH(対象, 検索)` | 後方一致 | `ENDSWITH("Chicago", "go")` | `true` |

```
// 「Taxi Affiliation」を含む会社かどうかをフラグ化
CONTAINS([company], "Taxi Affiliation")
```

::: warning 大文字・小文字を区別する
`CONTAINS` `STARTSWITH` `ENDSWITH` `FIND` はいずれも **大文字小文字を区別** します。大文字小文字を無視して検索したい場合は `CONTAINS(UPPER([company]), "TAXI")` のように両辺を揃えます。
:::

### 置換・空白除去

| 関数 | 説明 | 例 | 結果 |
|------|------|----|------|
| `REPLACE(対象, 検索, 置換)` | 全置換 | `REPLACE("Cash Payment", "Cash", "現金")` | `"現金 Payment"` |
| `TRIM(文字列)` | 前後の空白除去 | `TRIM("  hi  ")` | `"hi"` |
| `LTRIM(文字列)` | 先頭の空白除去 | `LTRIM("  hi  ")` | `"hi  "` |
| `RTRIM(文字列)` | 末尾の空白除去 | `RTRIM("  hi  ")` | `"  hi"` |

```
// 入力データの前後空白を一括除去
TRIM([company])
```

### 大文字・小文字変換

| 関数 | 説明 | 例 | 結果 |
|------|------|----|------|
| `UPPER(文字列)` | すべて大文字 | `UPPER("chicago")` | `"CHICAGO"` |
| `LOWER(文字列)` | すべて小文字 | `LOWER("CHICAGO")` | `"chicago"` |
| `PROPER(文字列)` | 単語の先頭だけ大文字 | `PROPER("john smith")` | `"John Smith"` |

```
// 表記ゆれを統一して比較したい場合
UPPER(TRIM([payment_type])) = "CREDIT CARD"
```

### 分割

| 関数 | 説明 | 例 |
|------|------|----|
| `SPLIT(文字列, 区切り, n)` | 区切り文字で分割し n 番目を返す。n は 1 始まり、負の値は末尾から | `SPLIT("a;b;c", ";", 2)` → `"b"` |

```
// "Taxi Affiliation Services" の最初の単語だけ
SPLIT([company], " ", 1)
```

::: tip フィールドメニューの「分割」機能
ディメンションを右クリック → 「変換」 → 「分割」を選ぶと、区切り文字を自動検出して `SPLIT` を含む複数の計算フィールドを一括生成してくれます。試行錯誤の初手として便利です。
:::

## 3. 文字列関数（正規表現）

より柔軟なパターンマッチが必要な場合は `REGEXP_*` 系を使います。Tableau は ICU 規格の正規表現を採用しています。

| 関数 | 説明 |
|------|------|
| `REGEXP_MATCH(対象, パターン)` | パターンに一致すれば true |
| `REGEXP_EXTRACT(対象, パターン)` | 最初の一致部分（または 1 番目のキャプチャ）を返す |
| `REGEXP_EXTRACT_NTH(対象, パターン, n)` | n 番目のキャプチャグループを返す |
| `REGEXP_REPLACE(対象, パターン, 置換)` | 一致部分を置換 |

```
// メールアドレスらしき形式かどうか
REGEXP_MATCH([email], '^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$')
```

```
// 文字列から最初に現れる数字列を抜き出す
REGEXP_EXTRACT([raw_text], '(\d+)')
```

```
// 「2024-04-15」から年と月をそれぞれ取り出す
REGEXP_EXTRACT_NTH([date_str], '(\d{4})-(\d{2})-(\d{2})', 1)   // 年
REGEXP_EXTRACT_NTH([date_str], '(\d{4})-(\d{2})-(\d{2})', 2)   // 月
```

```
// 連続する空白を 1 個にまとめる
REGEXP_REPLACE([company], '\s+', ' ')
```

::: info パターン文字列のエスケープ
Tableau の計算式内ではパターン全体をシングルクォートで囲むのが慣例です。`\d` `\s` などはそのまま動作しますが、`\` 自体を表現したい場合は `\\` のようにエスケープが必要です。
:::

::: warning 接続先によって挙動が異なる場合
ライブ接続のときは、データソース側のデータベース（PostgreSQL / SQL Server など）の正規表現エンジンに変換されることがあり、ICU と微妙に異なる動作になることがあります。期待どおりに動かない場合は抽出 (`.hyper`) に切り替えると Hyper エンジンで実行されます。
:::

## 4. 型変換

### 数値・文字列の相互変換

| 関数 | 用途 | 例 |
|------|------|----|
| `INT(値)` | 整数化（切り捨て） | `INT("123")` → `123`、`INT(3.9)` → `3` |
| `FLOAT(値)` | 実数化 | `FLOAT("3.14")` → `3.14` |
| `STR(値)` | 文字列化 | `STR(123)` → `"123"` |

```
// 数値を文字列と連結
"料金: " + STR([fare]) + " USD"
```

```
// 文字列の年齢を数値化（"30" → 30）
INT([age_str])
```

::: warning 変換失敗時は null
`INT("abc")` のように変換できない値は **エラーではなく null** になります。集計や条件式で挙動が変わるので、`ISNULL` でチェックするか、`REGEXP_MATCH` で事前検証するのが安全です。
:::

### 日付・日時への変換

| 関数 | 用途 | 例 |
|------|------|----|
| `DATE(値)` | DATE 型へ変換 | `DATE("2024-04-15")` → `2024-04-15` |
| `DATETIME(値)` | DATETIME 型へ変換 | `DATETIME("2024-04-15 10:30")` → `2024-04-15 10:30:00` |
| `DATEPARSE(書式, 文字列)` | 書式指定で日付化 | `DATEPARSE("yyyy/MM/dd", "2024/04/15")` |

```
// "20240415" を日付に変換
DATEPARSE("yyyyMMdd", [date_str])
```

```
// "Apr 15, 2024" のような書式
DATEPARSE("MMM d, yyyy", [date_str])
```

`DATE()` は標準的な書式なら自動判別してくれますが、独特の書式や日本語の月名などには弱いため、書式が決まっているなら `DATEPARSE()` を使うのが堅実です。

### 日付の構築

| 関数 | 用途 | 例 | 戻り型 |
|------|------|----|--------|
| `MAKEDATE(年, 月, 日)` | 日付を作る | `MAKEDATE(2024, 4, 15)` | DATE |
| `MAKEDATETIME(日付, 時刻)` | 日付と時刻を結合 | `MAKEDATETIME(DATE("2024-04-15"), MAKETIME(10, 30, 0))` | DATETIME |
| `MAKETIME(時, 分, 秒)` | 時刻を作る | `MAKETIME(10, 30, 0)` | TIME（環境による） |

```
// 年と月の数値から月初日を作る
MAKEDATE([year], [month], 1)
```

::: tip DATEPARSE と MAKEDATE の使い分け
- 文字列から日付を作る → `DATEPARSE`
- 数値（年・月・日）から日付を作る → `MAKEDATE`
- 既存の日付に時刻を貼り付ける → `MAKEDATETIME`
:::

## やってみよう

Chicago Taxi のデータを使って、数値・文字列・型変換の関数を試しましょう。

1. **データに接続**
   - `chicago_taxi_trips.hyper` に接続し、新規ワークシートを開きます。
2. **マイル単価を小数2位で丸める**
   - 計算フィールド `マイル単価` を作成:
     ```
     ROUND(IIF([trip_miles] = 0, NULL, [fare] / [trip_miles]), 2)
     ```
   - 行に `company`、列に `AVG([マイル単価])` を置き、テーブルにラベル表示します。
3. **乗車時間を「分:秒」表示にする**
   - 計算フィールド `所要時間表示`:
     ```
     STR(DIV([trip_seconds], 60)) + ":" +
     IIF(MOD([trip_seconds], 60) < 10, "0", "") +
     STR(MOD([trip_seconds], 60))
     ```
   - 詳細に `trip_id` を置いてレコード単位で確認します。
4. **会社名から先頭の単語を抜き出す**
   - 計算フィールド `会社略称`:
     ```
     SPLIT([company], " ", 1)
     ```
   - これを行に置き、件数 `COUNT([trip_id])` の多い順にソートします。
5. **支払方法の表記ゆれを統一**
   - 計算フィールド `支払方法 (正規化)`:
     ```
     PROPER(TRIM([payment_type]))
     ```
   - 元の `payment_type` と並べて比較し、結果が揃っていることを確認します。
6. **正規表現で「数字を含む会社名」を抽出**
   - 計算フィールド `数字を含む会社`:
     ```
     REGEXP_MATCH([company], '\d')
     ```
   - フィルターで `true` だけを表示し、該当する会社を一覧します。
7. **文字列日付を DATETIME に変換**
   - もしテキスト形式の日付列があれば、`DATEPARSE("yyyy-MM-dd HH:mm:ss", [date_str])` で変換し、Tableau が時系列軸として扱えることを確認します（このデータでは `trip_start_timestamp` がすでに日時型なので、`STR()` で一度文字列化してから戻す練習も可）。
8. **型変換の失敗を観察**
   - `INT("abc")` の計算フィールドを作り、結果が null になることを確認します。

## まとめ

- **数値関数** は丸め (`ROUND` `FLOOR` `CEILING`)、剰余 (`MOD` `DIV`)、累乗・対数 (`POWER` `LOG` `SQRT`) など一通り揃っています。
- `MIN` `MAX` は引数 1 個なら集計、2 個なら行レベルの最小/最大と挙動が変わるので注意が必要です。
- 文字列の検索系関数 (`CONTAINS` `STARTSWITH` `FIND`) は **大文字小文字を区別** します。`UPPER` などで揃えてから比較します。
- 複雑なパターンには `REGEXP_MATCH` `REGEXP_EXTRACT` `REGEXP_REPLACE` を使い、ICU 規格の正規表現が利用できます。
- 型変換は `INT` `FLOAT` `STR` `DATE` `DATETIME` `DATEPARSE` `MAKEDATE` などを場面に応じて使い分けます。変換失敗は **エラーではなく null** になる点に注意します。
- 文字列と数値を連結する際は `STR()` で明示変換が必須です。
